## 构造样例回归快照

本轮对初始 32 份构造回答运行当前规则：16 条发现冲突、8 条有证据支持、4 条待复核、4 条无法核验；已核验数字片段为 **42 / 48**。

这只是固定样例与当前规则的结果分布。42 包含已发现冲突的数字；它不是正确答案数，42 / 48 不是准确率。样例只有 8 个独立问题，不能据此估计真实模型质量或效果提升。当前这 32 份样例未额外触发“其他公司主体”疑点，不代表主体识别误报率为零。
