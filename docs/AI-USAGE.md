# AI 使用说明

记录日期：2026-10-25。本文描述当前交付状态，不代表已完成真实模型效果评测。

## 当前状态

**模型运行状态：notenabled（未启用）。** `lib/store.ts` 返回 `modelEnabled: false`，初始评测为 `mode: "rules"`、`modelStatus: "not_requested"`。网页使用规则与已保存证据快照，不调用付费模型，也不实时刷新金融数据。

`lib/model.ts` 已实现 DeepSeek 适配器，但当前网页 API 没有接入该调用路径。已完成的是 mock 验证；没有读取模型密钥、发送真实模型请求或获得模型付费调用授权。

## 模型适配器的限制

适配器固定使用 `deepseek-flash`，关闭思考模式，最多输出 1,200 token，20 秒超时且不自动重试。不向模型开放工具；问题、回答和证据作为不可信数据处理。返回需通过结构、证据 ID 和原文引用校验；模型疑点只能标为“待复核”或“无法核验”，不能直接成为官方事实结论。

同一模型生成并检查回答属于自检；即使以后接通，也不能把其判定作为独立真值。当前提示词文件是待验证设计，不能声称 answer-v2 的真实质量已高于 answer-v1。

工作台支持以 Prompt、模型、数据任一轴做单变量版本对照，固定问题、画像、其余两轴及评测器版本。导入时填写的模型与数据标签是提交者声明，不是平台已验证的模型调用记录或新证据集；改变 `dataVersion` 不会改变当前官方核验快照。只有一个版本时不显示成对效果结论。

## 费用说明

此前讨论的 **32 次生成＋32 次评测约 $0.06–$0.12** 是理论预算：假设每次生成输入 2,000、输出 600 token，每次评测输入 4,000、输出 800 token，合计输入 192,000、输出 44,800 token；关闭思考，输入按未缓存价格计算，不含额外重试或其他服务。

按当时查验的 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)，非高峰与高峰对应约 $0.05568–$0.11136。**这不是实际费用；建议的 $0.30 首轮预算尚未获用户授权。** 模型账号、余额、真实请求可用性和实际用量均未验证。iFinD 试用调用次数与模型费用分别统计。

若未来获得授权并接入，必须保存真实返回的 usage；未返回用量或超时的账单状态保持未知，不能记为零。估价函数按峰值计算，估价不能替代服务商账单。

接口依据：[Responses API](https://api-docs.deepseek.com/api/create-response/) · [思考模式参数](https://api-docs.deepseek.com/guides/thinking_mode/)。
