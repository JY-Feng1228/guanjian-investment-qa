## 产品流程

导入问答 → 运行规则核验 → 查看问题句子与原始证据 → 提交复核 → 保存修订版本 → 对比回归结果。

- **评测工作台**：筛选回答、查看数字与单位、期间、时效、推理及收益承诺等发现。
- **版本对比**：选择 Prompt、模型或数据其中一轴，固定问题、画像、其余两轴与评测器，比较发现变化。
- **治理记录**：保存评测历史、复核说明、访客反馈和操作记录，不覆盖旧版本。
- **画像对照**：同题同版本切换两种匿名画像，检查客观财务数字是否随画像改变。
- **模型复核**：独立查看 OpenAI 真实调用的疑点、原文引用、请求记录、用量及失败；不覆盖规则统计或原回答来源。
- **质量验收**：分别查看冻结规则基线、六题双模型对照、两份回答修订和后续证据核对；原结果与核对意见分开展示。

“未再出现的发现”不等于已证实修复；数字核验覆盖率不是正确率。

## 数据和 AI 的实际使用

原始 seed 为 **8 个独立问题 × 2 种画像 × 2 个版本，共 32 份构造回答**，含 5 个事实查询问题、3 个解释问题，原回答文本保持不变。`rules-1.3.0` 另加 3 条热点演示，新建空间共 35 条；旧空间只追加新演示，保留旧回答和评测。
回答由 AI 助手辅助起草并人为植入错误、修正及遗留问题，不是真实模型 API 输出，也不用于宣称模型准确率或提升比例。

金融证据来自贵州茅台 2024 年官方年报的选定事实，以及已保存的真实 iFinD 财务、公告检索响应摘录。
接口摘要与官方原文的冲突会保留展示；核验数值只采用已登记、核对过的原文事实。网页操作使用固定快照，不发起实时 iFinD 或付费模型请求。
新增问题明确包含“茅台”或“600519”才绑定现有证据；其他问题保留为无匹配证据，不根据回答中的自称补造来源。
导入可选填 Prompt、模型与数据版本标签；空值省略后采用默认标签。同题文本去空白、忽略英文大小写后归组，重复的完整版本组合会被拒绝。
版本标签由导入者声明；`dataVersion` 仅描述回答生成时的数据上下文，不代表上传或更换了核验证据。核验仍使用当前固定官方事实快照。某轴只有一个版本时显示空态，不制造对比结果。

AI 助手参与了方案、代码、测试、提示词、样例起草及原文工具核对。原文核对不等于用户人工签署或全篇独立审计。

第一批经授权使用官方 OpenAI `gpt-6-luna`、`quality-v1` 对预先固定的 8 个不同问题各复核一次，6 条成功、2 条失败，未重试或替换失败样本。6 / 8 是调用完成率，不是准确率；模型没有提出疑点也不代表回答通过。被复核回答仍是构造样例，真实 API 只生成了复核结果。

第一批预算上限为 **$0.30**。7 条已返回用量的请求合计输入 13,029、输出 1,355 token，保守费用估算 **$0.00393475**；另 1 条费用未知保留 $0.10，总预算占用估算 $0.10393475，均不等于账单。完整记录见 [首轮复核快照](public/evidence/openai-review-20261025.json)。

第二批另获 **$0.50** 上限授权，冻结 12 个新构造题的规则基线，选其中 6 题由 Luna、Sol 各复核一次，再检查 2 份回答修订稿，共 **16 / 16 次成功**，保守费用估算 **$0.09843175**，无未知费用。六题上两模型均为 TP 3、TN 3、FP 0、FN 0，仅表示与 AI 预标注的告警一致性。Sol 对修订稿的一条页码疑点，经官方 PDF 第 5 页核对排除；原输出与计分均保留。当前保留 Luna 作为成本基线，本小样本没有证明 Sol 更优，复杂任务优劣未验证。见 [质量验收说明](docs/QUALITY-VALIDATION.md)。

标签为 AI 预标注；用户转发的外部 AI 意见及本轮 AI 工具核对均不等于用户人工确认。`rules-1.1.1` 基线封存；已验收保底版 `rules-1.2.1` 在同12题上为 TP 6、FP 0、FN 0、TN 6，属于开发回归，不是新留出成绩。三条离线挑战仍均触发告警，C02已从主体误报改为正确的指标偏离提示，H08的附带主体误报消失。此前 `rules-1.2.0` 虽通过这12题，却因遗漏32条演示样例的专项回归，引入8条主体误报并漏检Q01/Q02的4处营收错误；本次补测试并修复，完整差异见质量验收说明。两批合计24次历史模型请求尝试保持不变，本次修复新增模型调用为0；网页保持 `modelEnabled: false`。

## 热点上下文（rules-1.3.0，已部署）

复用 `lib/evaluator.ts` 既有“今天 / 实时 / 近期热点 + 7 天”判断，新增带时间戳的 iFinD 新闻快照。内部 `kind: hotspot` 在证据来源标签显示为“热点上下文”，同时展示发布日期、来源工具和查询时间。新闻仅作背景；官方年报仍是已登记财务事实的依据。

- 晚于提问时间的热点：判为冲突。
- 超过 7 天的热点被当作“今天 / 最新”使用：标记时效问题；明确日期的历史背景可以保留。
- 热点回答中的同期间财务数值与登记原文不符：判为冲突；入门 / 经验画像均不能改写事实，热点中的数值不会注册成财务真值。

演示 `HOT-correct` 为注明 2026-10-19 日期的正确背景引用；`HOT-expired` 使用**模拟提问时间 2026-10-28** 展示过期问题；`HOT-overwrite` 展示热点改写财报冲突。页面搜索 `[HOT1]` 可筛出三条；在“证据来源”查看 HOT1 的日期与出处。API 导入含茅台的问题时，回答显式引用 `[HOT1]`（或快照标题）才绑定该热点；其他未登记新闻不自动补造证据。

提问时间优先使用 `askedAt`（API 可提供带时区 ISO 时间）；未提供则使用样本 `createdAt`，不能把它误称为已知的历史提问时间。接口只提供发布日时，按北京时间该日零点做日期粒度判断；无法判断同一天内发布与提问的先后。7 天为固定 7×24 小时窗口，查询时间不续期。规则依赖明确的证据编号/标题和直接数值句式，不裁定新闻全文真实性或所有语义改写。

本次 **iFinD 1/10 次查询，返回 3 条，采用 1 条；模型调用 0 次**。排除一条超出请求日期窗的旧新闻和一条动态估值页。原始响应只在 `private/hot-context-20261025/`，公开仅有[脱敏调用记录](public/evidence/hot-context-ifind-20261025.json)与摘要；完整[逐条回归对比](public/evidence/hot-context-regression-rules-1.3.0.json)单独存档，旧报告与冻结哈希不改写。

本版本已合并到 `main` 并沿用 Sites 流程部署，线上规则为 `rules-1.3.0`。`6337adf / rules-1.2.1` 保留为可回退的保底版本；公网 32 条 seed 和 3 条热点样本的逐条核对结果见本次交付记录。

## 技术栈

React 19、TypeScript、Vinext / Vite、Cloudflare Workers、D1 SQLite、Drizzle、Zod；图标使用 Lucide。
浏览器负责操作与展示，服务端负责核验、校验和记录。模型适配器使用原生 `fetch`，没有额外 Agent 编排框架。

## 本地运行

本轮验证环境为 Windows、PowerShell 7、Node.js 24.15.0。以下命令在项目根目录执行；使用 Node 24 可直接运行 TypeScript 测试。

首次获取源码、尚无依赖时执行；已有可用 `node_modules` 无需重复安装：

```powershell
npm run install:ci
```

构建生成本地 Worker 与数据库配置：

```powershell
npm run build
```

首次初始化本地 D1 时执行一次迁移。已有数据库不重复执行；本命令只操作本地数据库：

```powershell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_flowery_slapstick.sql
```

启动开发预览：

```powershell
npm run dev -- --hostname 127.0.0.1
```

打开终端输出的网址，默认是 `http://127.0.0.1:5173`。首次访问自动建立独立演示空间并载入样例。
如需检查构建后的 Worker，停止开发预览后执行 `npm start`，使用其打印的网址；这不会发布网站。

`npm run test:api` 需要先运行本地服务，默认请求 `http://127.0.0.1:5173`；非默认端口可设置 `QA_BASE_URL`。
HTTP 检查使用独立 cookie 演示空间，会写入明确标注的自动化测试样本与复核声明，不属于业务人工标注。
`rules-1.3.0` 当前通过 **53/53 项单元测试及类型检查**。视频已在 `1abfd39` 按计划更新，回归检查仅将该 mp4 排除于旧视频哈希断言；其余冻结文件照常检查，冻结基线未修改。原 32 条 seed 的状态与发现标题集合逐条保持 rules-1.2.1 不变，Q01/Q02 的 4 处营收冲突仍检出。HTTP、构建、浏览器与视频的检查由 [测试记录](docs/TESTING.md) 分版本记录；mock也不证明真实模型评测质量。

`scripts/verify-openai.ts` 与 `scripts/validate-quality.ts` 是分别对应两批次的受控本机入口，默认 `--plan` 不请求 API。付费执行只用于明确批准的固定计划；ledger 保留每次尝试、用量与未知费用预留。两个批次均已结束，不应删除 ledger 或重建批次以重跑。新的真实调用需要另行明确范围与预算，详见 [AI 使用说明](docs/AI-USAGE.md)。

当前规则已从冻结基线升级，第二批脚本的`--plan`、`--report`、`--run`会因`code-changed-after-freeze`停止；这是预期的冻结保护，不应修改冻结哈希绕过。`node scripts/check-hot-context-regression.ts` 不联网且只校验，不改写报告；已按计划更新的视频不参与旧哈希检查，新哈希见测试记录，其他冻结检查保持不变。旧 `report-quality-regression.ts` 会写旧文件，本次不运行；基线实现位置与复现边界见 [质量验收说明](docs/QUALITY-VALIDATION.md)。

## 演示空间和范围限制

- 匿名 cookie 为每个浏览器建立独立 D1 空间，记录在服务端保存；这不是团队账号系统，没有跨设备恢复。
- 规则升级不会自动覆盖已有空间的评测。旧浏览器可点击“核验当前列表”追加当前版本结果，旧评测及其复核仍保留；新空间直接使用当前规则，不需要清库。
- 每个演示空间最多 80 条样本、650 条评测历史、150 次操作；没有多人审核身份、权限分工或认证标签。
- 财务数字仅核验已登记历史财报指标。热点仅使用已保存、带发布日期的 iFinD 新闻片段；实时行情与新闻流未接入，现金流等未登记事实不自动补全。
- 热点在 7 天窗口内被引用时，规则只检查时间，不判断热点内容能否支撑行情或股价类说法；这类数字会显示为无法核验。
- 解析器已区分明确年度、季度、半年及前三季度；发现其他公司主体疑点时暂停数字支持判定。复杂省略、多期并列、同比计算及否定语境仍有覆盖边界，规则不是全面语义判定或法律合规认证。
- 人工复核是访客的主动声明，用户反馈是体验或异议；两者都不直接成为独立事实真值。
- 已完成的小批量真实语义复核不构成模型准确率评测；独立留出标注、在线生成及自动优化尚未完成。模型结论不能作为独立事实真值。
